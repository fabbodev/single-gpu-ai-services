# Start here

If this is your first time deploying the project, read these in order:

1. `../README.md`
2. `INSTALL.md`
3. `../ARCHITECTURE.md`
4. `MODELS.md`
5. `../SECURITY.md`
6. `VERIFY.md`

The implementation is deliberately small enough that the next step should be reading `gateway/app/main.py` and the files in `dispatcher/` rather than relying on a hidden installation script.
